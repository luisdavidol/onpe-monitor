# Monitor Elecciones Perú - ONPE

Monitoreo en tiempo real de resultados electorales de la ONPE.

## Candidatos

- **Keiko Fujimori** - Fuerza Popular (FP)
- **Roberto Sánchez** - Renovación Popular (RP)

## Instalación

```bash
npm install
```

## Uso

```bash
npm start
```

Luego abre http://localhost:3000 en tu navegador.

## Características

- Actualización automática cada 2 minutos
- Muestra diferencia de votos
- Barra de comparación visual
- Diseño responsive

## Requisitos

- Node.js 18+
- Puppeteer (se instala automáticamente)
